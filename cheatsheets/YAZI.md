# Yazi

## Shortcuts

```sh
f # fuzzy find file by name
S # search file content
gr # go to git root
gh # go to home dir
gD # go to Downloads
gd # go to ~/dev
/ or space # filter currently displayed stuff
s # easyjump
cx # chmod +x
c6 # chmod 644
c7 # chmod 755
cm # chmod (enter permissions manually)
```
