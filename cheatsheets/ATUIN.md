# ATUIN

## shortcuts

```sh
ctrl+r  # open tui
enter   # executes that command
tab     # select item and edit
alt+1-9 # selects item by number
ctrl+y  # copy the selected item to system clipboard

# inside the tui
ctrl+s # switch search mode fuzzy (default), prefix, full text
ctrl+r # cycle filter modes: global, host, session, dir, session+

# to delete a single entry
# open tui with ctrl+r navigate to the entry you want to delete
ctrl+o
# and after that
ctrl+d
# for more complex deletes check https://docs.atuin.sh/latest/guide/delete-history/#combining-filters

# VIM MODE 
j      # one entry down
k      # one entry up
ctrl+u # half a page up
ctrl+d # half a page down
gg     # first history entry
G      # last entry
M      # middle of visible entries
1-9    # select entry directly
i      # insert mode
esc    # normal mode
```
